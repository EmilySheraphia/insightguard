How thresholds work: When an employee fires an event, UEBA rules are scored against these role-specific thresholds. For example, a DevOps Engineer doing a 3 GB download won't trigger bulk_download if their Bulk DL threshold is 2000 MB. The weight multipliers (0.0–1.0) scale how heavily off-hours logins and VPN usage are penalised for a given role.
